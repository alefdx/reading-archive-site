Privacy policy

Last updated: 18 October 2026

Reading Archive is a personal tool used only by its developer. It is not offered to the public and has no other users.

What Google data the app accesses

  • Google Drive: only files the app creates (drive.file scope). It uploads documents into the owner's archive folder and reads those files back to avoid duplicates.
  • Google Sheets: the owner's own spreadsheets, to read category and author lists and to append one row per archived document.

How the data is used

Data is used only to file and catalogue the owner's own documents. To produce a title, summary and category, part of each document's text is sent to the OpenAI API. Data is not sold, used for advertising, or shared with anyone else.

Storage

OAuth tokens are stored only on the owner's own computers. Archived documents stay in the owner's Google Drive.

Google API Services User Data Policy

Reading Archive's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from Google Account → Third-party apps & services.

Contact

Questions can be raised through the developer's GitHub profile: github.com/alefdx.
